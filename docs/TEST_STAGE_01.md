# تست مرحله اول

این راهنما مربوط به نسخه مرحله اول است. در نسخه فعلی، قبل از اجرای ربات
[راه‌اندازی ذخیره‌سازی مرحله دوم](TEST_STAGE_02.md) نیز لازم است.

همه دستورها در PowerShell و پوشه `G:\Projects\TelegramBot_Mohammadi` اجرا شوند.

## نتیجه بررسی توسعه‌دهنده

- نصب وابستگی‌ها با Python 3.13.5 و ثبت نسخه دقیق در uv.lock موفق بود.
- ۳۲ تست خودکار، از جمله اجرای مستقیم در خروجی Windows با encoding قدیمی، پاس شد.
- بررسی Ruff و یکسان‌سازی قالب هر ۱۸ فایل Python پاس شد.
- نبودن تنظیمات با خطای کنترل‌شده و کد خروج ۲ تشخیص داده شد.
- اتصال واقعی Telegram اجرا نشده است؛ توکن واقعی در اختیار پروژه قرار نگرفته است.
- وضعیت مرحله: منتظر تست کاربر؛ مرحله ۲ هنوز شروع نشده است.

## ۱. آزمون خودکار بدون توکن و بدون اتصال تلگرام

```powershell
uv sync --locked
uv run --locked pytest -q
uv run --locked ruff check .
uv run --locked ruff format --check .
```

انتظار: تست‌ها و هر دو بررسی کیفیت پاس شوند. این آزمون‌ها از توکن ساختگی استفاده
می‌کنند و هیچ پیام واقعی به تلگرام نمی‌فرستند. فراخوانی‌های Telegram شبیه‌سازی می‌شوند.

## ۲. ساخت تنظیمات محلی

```powershell
uv run --locked python -m app.cli init-env
notepad .env
```

توکن BotFather را مقابل BOT_TOKEN قرار دهید. شناسه عددی حساب آزمایش‌کننده را در
BOOTSTRAP_ADMIN_IDS با قالب JSON وارد کنید؛ مثلاً `[123456789]`. این عدد نمونه است.
توکن و محتویات فایل را در گفتگو ارسال نکنید.

```powershell
uv run --locked python -m app.cli check-config
```

انتظار: پیام «تنظیمات معتبر است». این دستور فقط شکل تنظیمات را بررسی می‌کند و
اعتبار توکن در Telegram را تضمین نمی‌کند. توکن یا شناسه‌ها در خروجی چاپ نمی‌شوند.
اجرای دوباره init-env باید بدون تغییر فایل، پیام موجودبودن فایل بدهد.

## ۳. اتصال واقعی

```powershell
uv run --locked python -m app.main
```

با حساب مدیر، در گفتگوی خصوصی ربات `/start` بفرستید:

- پیام «مرحله ۱ از ۱۰» و دو دکمه راهنما و بررسی وضعیت نمایش داده شوند.
- هر دو دکمه کار کنند؛ `/help` و `/status` هم پاسخ دهند.
- متن دلخواه یا عکس، بازخورد ثبت نکند و پیام فعال‌نبودن دریافت پیام نشان دهد.
- از حسابی که در تنظیمات نیست، پاسخ «دسترسی شما به سامانه فعال نیست» دریافت شود.
- در گروه، ربات پاسخ ندهد. BotFather privacy mode را غیرفعال نکنید.
- خروجی ترمینال، متن پیام، نام، شناسه شخص و توکن را نشان ندهد.
- Ctrl+C ربات را متوقف کند.

برای تست چندحسابی، هر حساب باید جداگانه ربات را Start کند. فقط یک نمونه ربات را اجرا کنید.
اگر توکن نامعتبر باشد، خطای عمومی بدون چاپ توکن باید ظاهر شود. در اختلال شبکه ممکن است
کتابخانه منتظر اتصال بماند؛ Ctrl+C و بررسی شبکه راه تشخیص مرحله فعلی است.

## گزارش نتیجه

نتیجه تست‌های خودکار و گزینه‌های بالا را ارسال کنید. در صورت خطا، متن عمومی خطا
کافی است؛ `.env`، توکن یا محتوای حساس پیام‌ها را نفرستید.
