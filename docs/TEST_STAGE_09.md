# تست مرحله ۹: دسترسی مدیریتی بازخوردهای گروه

در این مرحله نمای بازخوردهای اولیه بر اساس سه نقش نهایی محدود شده است. مدیر
اصلی همه گروه‌ها را می‌بیند؛ مدیر داخلی فقط موارد مربوط به گیرندگان گروه خودش
را می‌بیند؛ کاربر عادی به این نما دسترسی ندارد.

## آزمون دستی

1. با مدیر اصلی دو مدیر داخلی و دو گروه جدا بسازید.
2. در هر گروه حداقل دو عضو قرار دهید و داخل هر گروه یک بازخورد ارسال کنید.
3. مدیر داخلی گروه اول وارد `/admin ← بازخوردهای گروه من` شود؛ فقط گیرنده و
   بازخورد گروه اول باید نمایش داده شود.
4. همین بررسی را برای مدیر گروه دوم انجام دهید.
5. مدیر اصلی وارد «همه بازخوردهای اولیه داخلی» شود؛ هر دو مورد همراه نام گروه
   باید نمایش داده شوند.
6. هیچ نما نباید نام یا شناسه نویسنده را نمایش دهد.

اگر گیرنده با مدیر اصلی به گروه دوم منتقل شود، مورد قبلی او باید فوراً از فهرست
مدیر اول حذف و در فهرست مدیر دوم ظاهر شود. دکمه ذخیره‌شده یک مورد از گروه دیگر
نیز باید با خطای دسترسی رد شود؛ مخفی‌کردن صرف دکمه کافی نیست.
