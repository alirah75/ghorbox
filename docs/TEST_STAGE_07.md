# تست مرحله ۷: حذف گزارش پیام

در این مرحله قابلیت گزارش پیام به‌طور کامل از مسیر کاربر و مدیر حذف شده است.
جدول قدیمی `reports` فقط برای سازگاری دیتابیس باقی می‌ماند و برنامه رکورد تازه‌ای
در آن ایجاد نمی‌کند.

## آزمون دستی

1. یک بازخورد داخلی بفرستید و آن را از تاریخچه فرستنده و گیرنده باز کنید.
2. مطمئن شوید دکمه «گزارش پیام» در هیچ‌کدام از پیام‌ها وجود ندارد.
3. با مدیر اصلی یا داخلی وارد `/admin` شوید؛ گزینه «بررسی گزارش‌ها» نباید وجود داشته باشد.
4. پنل «بازخوردهای اولیه داخلی» باید همچنان بازخورد اولیه را بدون هویت نویسنده نشان دهد.
5. گزارش هفتگی آماری باید باقی بماند، اما معیار «گزارش‌های تخلف» را نمایش ندهد.

callback ذخیره‌شده از نسخه قبلی برای `mod_report_save` باید با خطای امن رد شود و
هیچ رکوردی نسازد. گزارش‌های قدیمی مانع اجرای سیاست نگهداری و حذف محتوای منقضی
نمی‌شوند. قابلیت بستن گفتگو نیز در مرحله ۸ حذف شده است.
